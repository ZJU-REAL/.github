# ZJU-REAL/.github

This repository powers the profile page at [github.com/ZJU-REAL](https://github.com/ZJU-REAL).

- Edit the page in [`profile/README.md`](profile/README.md).
- Figures and covers live in [`profile/assets/`](profile/assets/); both light and dark variants are provided.
- The banner and research map are generated: edit the data at the top of [`tools/figures.py`](tools/figures.py) and run `python3 tools/figures.py` from the repository root.
